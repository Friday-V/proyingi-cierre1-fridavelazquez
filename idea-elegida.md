## Idea seleccionada

**Organizador inteligente modular para objetos importantes**

## ¿Por qué elegí esta idea?

Elegí esta idea porque es un problema que he experimentado personalmente al olvidar objetos importantes como la credencial, las llaves o el cargador. También considero que es una idea que puedo realizar con los conocimientos y herramientas que estamos aprendiendo en el curso, ya que utiliza sensores, un microcontrolador y piezas que se pueden fabricar.

Otra razón por la que elegí esta idea es que quiero que el organizador sea modular. De esta manera, se podrían agregar, quitar o cambiar los espacios dependiendo de los objetos que cada persona necesite controlar.

## Pieza física del prototipo

El prototipo tendrá una base de MDF de 3 mm cortada con láser y diferentes módulos que se puedan colocar sobre ella. Cada módulo tendrá un espacio para un objeto y un sensor FSR debajo para detectar si el objeto está presente.

La base permitirá colocar varios módulos, por ejemplo, uno para las llaves, otro para la credencial y otro para el cargador. El sensor enviará la información al XIAO, que determinará si el objeto está presente o falta y, dependiendo de la programación, podrá generar una alerta.
